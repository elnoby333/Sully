# Sandy Private Surprise — نسخة بقاعدة بيانات

الموقع أصبح Full Stack: تسجيل دخول فعلي، جلسات آمنة، قاعدة بيانات SQLite، رفع صور/أغاني/فيديوهات، وحساب إدارة لإظهار الملفات أو إخفائها وحذفها.

## التشغيل محليًا

يتطلب Node.js 22.13 أو أحدث (لأن قاعدة SQLite مدمجة في Node؛ تم الاختبار على Node 26).

```powershell
npm install
npm start
```

بعد ذلك افتح `http://localhost:3000`.

## حسابات البداية

| الحساب | اسم المستخدم | كلمة السر |
| --- | --- | --- |
| المستخدم | `sandy` | `1234` |
| الإدارة | `admin` | `change-me-now` |
| المستخدم الثالث | `private-user` | `change-this-too` |

**غيّر كلمة مرور الإدارة قبل النشر.** انسخ `.env.example` إلى ملف `.env` ثم غيّر `ADMIN_PASSWORD` و`SESSION_SECRET` قبل أول تشغيل. إذا شغّلت الموقع سابقًا، احذف ملف `data/sandy.db` بعد أخذ نسخة احتياطية حتى تُنشأ الحسابات بالقيم الجديدة.

## خصوصية المحتوى

كل ملف له مالك. ملفات ساندي لا تظهر ولا تُفتح إلا عند تسجيل الدخول بحساب `sandy` أو `admin`. الحساب الثالث لا يمكنه مشاهدة أو فتح روابط ملفات ساندي، والعكس صحيح؛ المدير فقط لديه صلاحية مشاهدة وإدارة كل الملفات.

## أين تُحفظ البيانات؟

- `data/sandy.db`: ملف قاعدة البيانات (المستخدمون وبيانات الميديا).
- `uploads/`: الملفات المرفوعة نفسها.

خذ نسخة احتياطية من المجلدين معًا عند نقل الموقع أو رفعه على الاستضافة. لا ترفع `data/` أو `uploads/` إلى GitHub إذا كانت تحتوي على محتوى خاص؛ استخدم استضافة تدعم Node.js وتخزينًا دائمًا.

## حدود الرفع

المسموح: MP3/WAV/OGG/M4A، JPG/PNG/WebP/GIF، MP4/WebM/MOV، وبحد أقصى 150MB للملف. الرفع يتطلب تسجيل الدخول.
